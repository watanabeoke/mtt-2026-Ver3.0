Policy Workshop Capture & Skill Analysis Intake

เครื่องมือ HTML สำหรับเก็บข้อความจากการระดมสมอง เสียงจากการหารือ และรายละเอียด workshop เพื่อส่งต่อเข้าสู่ระบบ Skill / Agent วิเคราะห์นโยบาย
Policy Cycle Menu

0) ตั้งค่า Workshop

กรอกข้อมูลพื้นฐานเพื่อให้ระบบสร้างไฟล์วิเคราะห์ที่อ่านต่อได้ง่าย ทั้งสำหรับมนุษย์และ Agent
Output ที่ระบบนี้ออกแบบให้ส่งต่อไปวิเคราะห์ต่อ
Raw transcript Brainstorming notes Problem statement Policy option matrix Decision brief Implementation canvas Evaluation framework Skill-ready JSON

A) จับเสียง / ระดมสมอง / Raw Discussion

ใช้ช่องนี้เก็บเสียงจากการหารือ หรือวางข้อความจากการประชุม เพื่อจัดหมวดเข้าสู่ขั้นตอนนโยบาย
ยังไม่เริ่มบันทึกเสียง
หมายเหตุ: ฟังก์ชันไมโครโฟนใช้ Web Speech API จึงมักทำงานดีที่สุดบน Chrome และอาจต้องเปิดผ่าน HTTPS/localhost

1) Agenda Setting / Problem Identification

เปลี่ยน “ประเด็นทั่วไป” ให้เป็น “ปัญหาสาธารณะ” ที่รัฐควรลงมือ

2) Policy Formulation

พัฒนาทางเลือกเชิงนโยบายและทดสอบความเป็นไปได้

3) Decision-Making / Adoption

เลือกแนวทางที่เหมาะสมและได้รับการรับรองอย่างเป็นทางการ
ให้คะแนน 1–5 เพื่อช่วยเปรียบเทียบทางเลือก: Alignment, Feasibility, Support, Public Value, Equity, Transparency, Readiness

4) Implementation

แปลงนโยบายให้เป็นระบบงานจริงที่มีเจ้าของและวัดผลได้

5) Evaluation

ประเมินผลเพื่อตอบว่านโยบายควรเดินต่อ ปรับ ขยาย หรือยุติ

S) Skill Analysis Prompt

สร้าง prompt เพื่อส่งให้ระบบ Skill / Agent วิเคราะห์ต่อ โดยใช้ข้อมูลทั้งหมดจากฟอร์มนี้
เลือกงานวิเคราะห์ที่ต้องการให้ Skill ทำต่อ

X) Export JSON / Markdown / Text

นำออกเป็นข้อมูล structured เพื่อใช้กับ Agent, Skill, Notebook, Google Sheet, Database หรือรายงานต่อไป
กด Preview JSON หรือ Download เพื่อสร้างไฟล์
